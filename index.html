Vertex OS

Vertex OS is an independent Linux-based operating system designed for bare-metal hardware deployment, automated GPT partitioning, and seamless cloud synchronization.

About Vertex OS

Vertex OS is an independent Linux-based operating system built for developers, system administrators, and everyday users who demand sovereignty over their personal computing. Vertex OS provides a complete desktop environment with an automated hardware deployment installer, Btrfs filesystem architecture, and native local productivity tools.

The operating system includes the Vertex OS Installer and the Vertex Cloud Sync background subsystem, which allow users to optionally connect their personal Google Drive storage directly into the local Linux virtual filesystem.

Google OAuth 2.0 Integration

Google API & Google Drive Integration Purpose

Vertex OS utilizes Google OAuth 2.0 to provide optional, sovereign cloud storage synchronization for users who choose to connect their Google Drive account.

1. Purpose of Access & Scopes Requested

Vertex OS requests the Google Drive API scope (https://www.googleapis.com/auth/drive or https://www.googleapis.com/auth/drive.file) and basic account identity (userinfo.email) solely to:

  • Mount the user's remote Google Drive cloud storage to a local virtual directory path at ~/Vertex Cloud on their computer.
  • Enable the user to browse, open, edit, and back up personal files directly through standard Linux file managers (such as Nautilus or Dolphin).
  • Facilitate asynchronous local file synchronization powered by the open-source rclone VFS engine.

2. Local-Only Token Storage & Zero Telemetry

All OAuth tokens and configuration keys are stored strictly and exclusively on the user's local disk at ~/.config/rclone/rclone.conf with POSIX 0600 (owner read/write only) permissions. Vertex OS transmits zero tokens, zero telemetry, and zero user data to any remote server operated by The Vertex Project or third parties.

3. Google API Services User Data Policy Compliance

Vertex OS Privacy Policy

Effective Date: August 20, 2026 • Published by The Vertex Project

1. Executive Privacy Principle

The Vertex Project ("Vertex OS", "we", "us", or "our") is built on the principle of complete user sovereignty. Vertex OS does not collect telemetry, does not log user activity, does not maintain remote user databases, and does not sell or share any user information.

2. Local Credential Storage for Google Drive

When you connect your Google Drive account, your OAuth 2.0 access and refresh tokens are stored exclusively on your physical machine at ~/.config/rclone/rclone.conf. No credentials or files are ever sent to or processed by external Vertex servers.

3. Zero Telemetry & Diagnostics

Vertex OS does not transmit crash telemetry, hardware identifiers, MAC addresses, or IP logs. All system processes operate offline-first.

4. User Control and Token Revocation

You may revoke Vertex OS access to your Google account at any time either by deleting ~/.config/rclone/rclone.conf locally, or by managing authorized third-party apps in your Google Account Security Dashboard.

5. Contact Information

For privacy inquiries, contact: the.vertex.project.main@gmail.com
